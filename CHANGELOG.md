# Changes

## 1.1

- **Radio**: a new screen, before Settings, with public stations from the Radio Browser directory: popular, by country, by genre, search, favorites and recent; shows the song playing when the station announces it.
- **Remote**: the page the console serves is now a full remote control. Controller buttons, live channels, movies and series (with episodes) to browse and play from, search, radio, typing into the TV keyboard, and now-playing controls, alongside the existing set-up tools.
- The page runs whenever the app does (it can be switched off), and its address carries a key shown only on the console.
- **Settings → About**: version, credits, where the data and log are.
- Fixed a small amount of memory lost each time a background task finished.
